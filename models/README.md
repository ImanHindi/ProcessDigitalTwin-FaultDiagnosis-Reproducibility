# Physical-process model snapshots

The accepted physical simulation uses the v4.6.2 process model; v4.6.3 denotes the measurement/fault campaign and Final19 analytics layer, not a newly validated hydraulic model.

Only reviewed, distributable `.slx` and related model-definition source should be committed. Trained binary model checkpoints and generated caches are excluded from this Git repository and should be referenced through an authenticated archival release.
