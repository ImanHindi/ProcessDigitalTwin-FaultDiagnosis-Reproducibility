# Data, software and reproducibility availability

## Public lightweight software package

The repository contains Python source code for Final19 training, diagnostics, anomaly modelling, locked-split checks, and journal figure generation. It also contains the original study's run-level metadata, frozen split assignments, evaluation summary tables and prediction exports. These allow independent checking of headline **test statistics without retraining**.

## Assets requiring a separate archival deposit

The Git repository intentionally excludes the original 1,900 raw simulation trajectories, training caches, heavyweight model checkpoints, and machine-specific/local build artifacts. Full model retraining and the operator HMI require these assets plus the MATLAB process model and associated tooling. GitHub/Zenodo releases should explicitly distinguish complete/restricted datasets from lightweight evaluation evidence.

## Citation-ready availability statement (software and evaluation evidence)

> The Python analysis code, locked Final19 run assignments, campaign metadata and archived model-evaluation exports supporting the simulation-domain results will be made available in the public AlKaseeh Process Digital Twin reproducibility repository (version 1.1.0, GitHub repository URL and archived release DOI to be recorded after publication). The full 1,900-run time-series campaign and trained model binaries are not included in the lightweight Git repository; access to additional artifacts is documented separately. No plant telemetry was used for the released simulation-domain benchmark.

**Do not cite an unverified DOI as the project archive.** An archival DOI can be generated by linking a public GitHub release to Zenodo, or by depositing a separate large-data archive on Zenodo. The DOI, repository owner and public access level must be confirmed before updating a journal's data availability statement.

## Version and provenance

- Frozen study campaign: Scientific1900 / Final19
- Physical-model baseline: v4.6.2
- Measurement/campaign layer: v4.6.3
- Reproducibility software release: v1.1.0 (repository packaging version; not a new experiment)
- Validated independent evaluation runs: 1,900

The `ml/reports/final19` test and selection reports are archived results, not generated synthetic placeholders. The upstream original training scripts were taken from the supplied Final19 patch source; full MATLAB/HMI sources were not present in this small software snapshot and are incorporated only through the local release preparer.

The downloaded v1.1.0 source candidate contains the complete verified Final19 patch code but not the original accepted `.slx` or Streamlit source, which must be added using the source-completeness-checked local release builder before claiming full software-source availability.
