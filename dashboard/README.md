# Streamlit operator HMI

The operator dashboard is a research advisory interface for replay/telemetry, 19-class fault probabilities and healthy-only anomaly output. The full original Streamlit application was not included in the small Final19 patch archive. It can be imported from the local project by `scripts/prepare_local_release.py`, after a source/privacy review.

The dashboard must not command safety-critical actuators or be described as a live PLC integration without independent commissioning evidence.
