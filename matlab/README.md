# MATLAB/Simulink physical simulation source

The accepted physical model is the **v4.6.2** Simscape Thermal Liquid process baseline. The local-source assembler can import eligible MATLAB `.m` source and reviewed `.slx` model files from the original physical project. The MATLAB/Simscape physical model itself was not present in the lightweight Final19 code archive.

**The presence of this directory is not evidence of an included runnable MATLAB model.** Full simulation reproduction requires the actual model, its dependencies, parameter configuration and available MATLAB/Simscape runtime.
